## 変えるもの

| 項目 | 今（Hallmark） | これから（スキル） |
|---|---|---|
| 字 | Host Grotesk ＋ Atkinson Hyperlegible Mono | **Geist**（数字・コマンドは Geist Mono）。日本語は Windows で游ゴシック、Mac でヒラギノ |
| 字の大きさ | 独自の段 | Tailwind の段だけ：見出し 30px、区切りの見出し 20px、本文 14・16px、小さい字 12px、安全度 96px、数字 36px |
| 余白 | 独自の段 | 2・4・8・12・16・24・32・40・48・64・80・96px だけ |
| 角の丸み | 10px・6px | カード 16px、ボタン 8px、絞り込みと検索は丸い錠剤形。入れ子は「外の丸み−すき間」 |
| ダークの色 | 青みのある灰色 | 背景 #000000、パネル #181818、少し明るい面 #1F1F1F、指を置いたとき #272727、線 #313131 |
| ライトの色 | 紙っぽい生成り | 背景 #FAFAFA、パネル白、線 #E4E4E4、字 黒／#333／#666 |
| サイドバー | 右側だけ線 | 四辺に線のある浮いたパネル（片側だけの線は使わない決まり） |
| アイコン | 手描き | Phosphor |
| ボタン | 高さ 32〜36px | 余白 上下8・左右12、16px 太字（小さいものは 14px 太字）。主ボタンは1画面に1つ |
| 動き | 短い動き | 決めた曲線（0.32, 0.72, 0, 1）で 0.7秒。画面を開くと、カードが下から浮かび上がる（ぼかし→くっきり、0.8秒）。動きを減らす設定なら動かさない |
| 読み込み中 | 「…」と進み具合の棒 | 形をまねた灰色の板（スケルトン）。診断中の進み具合の棒はそのまま |
| 文の決まり | ― | 文中にハイフンを使わない（例：「架空SNS-B」のような名前は除く）。最後の行に1語だけ残さない |

## 変えないもの

- 画面の並び（サイドバー＋上の帯）と、すべての機能
- 色の意味：琥珀＝押すもの、赤＝漏洩・事故だけ、青＝測った数字、緑＝よくなったこと
- 日本語・英語、ライト・ダーク・パソコンに合わせる、の切り替え
- キーボード操作（⌘K／Ctrl K、↑↓、Enter、S）

## スキルの中で、アプリには使わない決まり

- **浮いた錠剤形のナビ、大きな一言の区切り、最初の画面の見出しのグラデーション**：紹介ページ用の決まりなので、アプリには使わない（アプリには「最初の画面」や「売り込み」がないため）。
